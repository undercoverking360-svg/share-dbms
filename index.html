💻 Desktop App Setup Guide (Step-by-step / सेटअप गाइड)

  1. Step 1: Download & Unzip / डाउनलोड और अनज़िप
    Upar diye gaye link se VaultPulse-Desktop-v1.0.0.zip download karein aur extract/unzip karein.
    (Download the zip file from the link above and extract it on your Windows PC.)
  2. Step 2: Run VaultPulse.exe / ऍप चालू करें
    Folder mein se VaultPulse.exe par double-click karke start karein. Network/Wi-Fi server instant chalu ho jayega!
    (Double click VaultPulse.exe. App starts silently in System Tray with local server live.)
  3. Step 3: Connect Mobile over Wi-Fi / फोन कनेक्ट करें
    Website par "Connect Phone" button dabayein. PC ka local Wi-Fi IP (e.g. 192.168.x.x) auto-detect hokar QR Code upgrade ho jayega. Apne mobile camera se scan karke high speed Wi-Fi direct transfer enjoy karein!
    (Click "Connect Phone" on website. Scan the QR code with your mobile camera to transfer unlimited files at Wi-Fi LAN speed.)
